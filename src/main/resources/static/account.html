1. Connect your application

    
Install the plugin with your favorite build tool. It needs Java 17 and JobRunr 8.5.0 or later.

    

      
      
    

    
<dependency>
    <groupId>org.jobrunr</groupId>
    <artifactId>jobrunr-mcp</artifactId>
    <version>1.0.0-beta.0</version>
</dependency>

    
implementation("org.jobrunr:jobrunr-mcp:1.0.0-beta.0")

    
Then give it your connector token. The JobRunr dashboard does not have to run.
