MCP Free for JobRunr OSS

Let your AI agent operate your JobRunr cluster

Connect your application once, then ask Claude Code, Cursor or VS Code what is going on with your background jobs, and have it fix what it can.

  • See failing jobs with their exception and full history, straight from your editor
  • Group failures by cause during an incident, instead of paging through the dashboard
  • Requeue a whole group after the fix, with a preview you approve first
  • The JobRunr docs are in the same server, so your agent reads the right page next to the stack trace

How it works

  1. Sign up and confirm your email. You get a connector token and an agent token.
  2. Install the plugin with your favorite build tool. It needs Java 17 and JobRunr 8.5.0 or later. 
    <dependency>
    <groupId>org.jobrunr</groupId>
    <artifactId>jobrunr-mcp</artifactId>
    <version>1.0.0-beta.0</version>
</dependency>
    implementation("org.jobrunr:jobrunr-mcp:1.0.0-beta.0")
  3. Add the connector token to your application config. Your app opens an outbound connection to us, so there is no port to open.
  4. Add the agent token to your MCP client. One URL, one header.
